Gradient descent is one of the most fundamental optimization algorithms in machine learning. In this post, I'll walk through the mathematical foundations and demonstrate how it works in practice.

## The Core Concept

The goal of gradient descent is to minimize a cost function $J(\theta)$ by iteratively adjusting parameters $\theta$ in the direction of steepest descent. The update rule is elegantly simple:

$$
\theta_{t+1} = \theta_t - \alpha \nabla J(\theta_t)
$$

where $\alpha$ is the learning rate and $\nabla J(\theta_t)$ is the gradient of the cost function with respect to $\theta$.

## A Simple Implementation

Here's a basic implementation in Python:

```python
import numpy as np

def gradient_descent(X, y, learning_rate=0.01, epochs=1000):
    """
    Perform gradient descent for linear regression.

    Args:
        X: Feature matrix (n_samples, n_features)
        y: Target vector (n_samples,)
        learning_rate: Step size for parameter updates
        epochs: Number of iterations

    Returns:
        theta: Optimized parameters
    """
    n_samples, n_features = X.shape
    theta = np.zeros(n_features)

    for epoch in range(epochs):
        # Compute predictions
        y_pred = X @ theta

        # Compute gradient
        gradient = (1/n_samples) * X.T @ (y_pred - y)

        # Update parameters
        theta -= learning_rate * gradient

        if epoch % 100 == 0:
            loss = np.mean((y_pred - y)**2)
            print(f"Epoch {epoch}: Loss = {loss:.4f}")

    return theta
```

## Convergence Considerations

The choice of learning rate $\alpha$ is critical. If $\alpha$ is too large, the algorithm may overshoot the minimum. If too small, convergence will be unnecessarily slow. The optimal learning rate often satisfies:

$$
0 < \alpha < \frac{2}{\lambda_{\max}}
$$

where $\lambda_{\max}$ is the largest eigenvalue of the Hessian matrix.

## Variants and Extensions

Several variants improve upon vanilla gradient descent:

- **Stochastic Gradient Descent (SGD)**: Updates parameters using single samples, enabling faster iterations on large datasets
- **Mini-batch Gradient Descent**: Balances computational efficiency with gradient accuracy
- **Momentum**: Accumulates gradients over time to accelerate convergence
- **Adam**: Adapts learning rates per parameter using first and second moment estimates

## Conclusion

Gradient descent remains a cornerstone of modern machine learning, underlying everything from linear regression to deep neural networks. Understanding its mathematical foundations and practical considerations is essential for any practitioner.
