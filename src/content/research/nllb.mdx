## Summary

No Language Left Behind (NLLB) is a large-scale effort to build a single multilingual translation model that supports 200 languages, with a focus on low-resource languages underserved by existing translation systems.

## Impact

- **1,500+ citations** since the arXiv posting in 2022
- Published in **Nature** (June 2024); Nature published an accompanying editorial commentary
- NLLB-200 models widely adopted on HuggingFace across multiple size variants
- Community applications built on NLLB, including RTranslator (236-point Show HN)
- Yann LeCun posted about the work on Threads

## My Contribution

I helped write the human evaluation section of the paper, contributing to the design and documentation of the evaluation framework used to benchmark translation quality across language pairs. This involved large-scale human annotation campaigns and the statistical models used to derive quality estimates from noisy human judgments.

## Key Results

- A single model supporting direct translation between 200 languages (40,000+ directions)
- Significant quality improvements over prior multilingual models, especially for low-resource language pairs
- Comprehensive human evaluation across a broad set of languages, establishing benchmarks for future work
